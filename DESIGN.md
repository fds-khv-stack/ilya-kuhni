# Илья кухни — редакционная визуальная система

## Замысел
Мастерская мебели в Хабаровске. Сначала показать работу и материалы в реальных интерьерах, затем познакомить с человеком и дать простой путь к разговору. Единственный контакт клиентов — +7 914 771-91-48. Telegram Дмитрия находится только в подписи разработчика.

## ДНК страницы
- Жанр: спокойный интерьерный журнал.
- Композиция: фотографический первый экран, живая сетка работ, тёмный рассказ мастера, типографская последовательность этапов, большой телефон в финале.
- Фотографии занимают большую часть ключевых экранов. Никаких декоративных ореолов, карточек с эффектом стекла или автоматического движения.
- Палитра: тёплая бумага `--color-paper`, древесный графит `--color-dark`, бронза `--color-accent` только для малых деталей. Переменные находятся в `tokens.css`.
- Заголовки: Cormorant Garamond, основной текст: Manrope. Крупные, но тихие заголовки; короткие подписи; абзацы с удобной длиной строки.
- Ритм: щедрые интервалы между большими фотографиями и короткие расстояния внутри смысловых групп. Для кнопок — прямоугольная форма, никаких градиентных бликов.

## Путь посетителя
Первый экран → работы по семи направлениям → мастер → услуги и этапы → вопросы → звонок. Каталог показывает 165 фотографий; фото открываются с клавиатуры, стрелки переключают кадры. На телефоне звонок закреплён внизу с учётом safe area.

## Технические границы
Существующий React и TypeScript сохраняются. Стили добавлены поверх прежних слоёв как `src/atelier.css`; `tokens.css` содержит новые токены. В дальнейшем старые слои можно аккуратно консолидировать, когда визуальная версия будет принята. Внешняя отправка заявок не используется. Цены, отзывы, материалы проектов и сроки не выдуманы.

## Контент для следующей итерации
Нужны портрет Ильи, фотографии работы в мастерской, краткие истории избранных заказов с размерами и материалами, подтверждённые условия гарантии и отзывы с разрешением на публикацию.
