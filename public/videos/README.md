# Интерьерные анимации

Файлы предоставлены пользователем для интеграции в сайт 22 октября 2026 года.

На странице обозначены как интерьерное вдохновение, отдельно от работ мастерской.
Оптимизированы в H.264, без аудиодорожки, с faststart. У второго ролика удалены
встроенные чёрные поля (crop 720:732:0:274). WebP-постеры взяты из соответствующих
видео. Воспроизведение по нажатию; после первого включается второй, затем остановка.
Исходные загруженные файлы не изменялись.
