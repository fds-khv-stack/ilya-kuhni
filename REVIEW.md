## Главные выводы

Основа уже есть: React, TypeScript, локальные WebP, семантические секции, SEO-метаданные, JSON-LD, GitHub Pages CI. В каталоге 165 фотографий в семи направлениях. Переписывать сайт с нуля не требуется.

### P0 — путь до заявки

- `src/App.tsx`: форма собирает текст в состоянии React, не отправляет заявку. Услуги ведут в эту форму; Max также открывает её без настоящего контакта. Сначала согласовать реальные каналы, затем добавить явный переход к мастеру после подготовки текста. Серверный сбор заявок — отдельный этап.
- Контакты расходятся: телефон +7 914 771-91-48, WhatsApp +7 914 400-99-22. В `index.html` JSON-LD указан второй номер. Telegram мастерской совпадает с подписью разработчика @Dmitrii_khv27. Это может быть намеренно, но требует проверки владельцем. Автоматически заменять нельзя.
- Текст формы утверждает, что контакты ещё не подключены, хотя часть ссылок уже работает. После согласования контактов привести описания в соответствие с фактическим поведением.

### P1 — пользовательский опыт

- Галерея состояла из кликабельных img без клавиатурного доступа. На телефоне отсутствовали видимые кнопки перелистывания. В этой ветке добавлены кнопки открытия, стрелки, счётчик, перевод и возврат фокуса.
- Эффект Modal зависел от нового onClose при каждом рендере: это повторно запускало очистку, возврат и установку фокуса. В этой ветке обработчик хранится в ref; эффект блокировки прокрутки запускается один раз.
- Автоматическая смена hero и фото плиток продолжалась при reduced motion. В этой ветке проверяется системное предпочтение; плавный переход к контактам также его учитывает. Остаётся добавить общую кнопку паузы карусели и обработку изменения предпочтения во время сеанса.
- Вступительная заставка держится 2,1 секунды. Рекомендуется убрать обязательное ожидание перед первым экраном.
- `initLux()` вызывается сразу после `createRoot().render()`: нельзя полагаться, что React уже создал DOM. Перенести инициализацию эффектов в жизненный цикл React с очисткой слушателей.

### P1 — сборка

- До исправления `tsc --noEmit` завершался ошибкой TS2339 (`import.meta.env`). Добавлены `vite/client`, команда typecheck и обязательная проверка типов перед Vite build.
- `netlify.toml` публикует build без команды сборки, а Vite использует /ilya-kuhni/. Для альтернативного хостинга требуется отдельная конфигурация base и сборки. Текущий GitHub Pages workflow выполняет npm run build.

### P2 — содержание и сопровождение

- Каталог стоит превратить в кейсы: задача клиента, размеры, материалы, фурнитура, решение и фотографии результата. Цены, сроки, отзывы и гарантии добавлять только после подтверждения.
- В блоке «О мастере» показана мебель. Реальный портрет и фотографии процесса могли бы усилить личное позиционирование.
- DESIGN.md расходится с реализацией: описывает другую палитру, отсутствие автопрокрутки и неподключённые контакты. Обновить после согласования продукта.
- App.tsx объединяет данные, формы, диалоги, галерею и страницу; три слоя CSS переопределяют стили. Следующим этапом выделить компоненты и единые токены без изменения внешнего вида.
- Канонический URL и метаданные уже присутствуют. В дальнейшем добавить sitemap/robots под подтверждённый домен и оценить prerender, чтобы важный контент присутствовал в HTML до запуска JS.
